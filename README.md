# ECOVACS Robotics India & Frootle India Experience Portal

Official interactive web experience and product showcase for **ECOVACS Robotics** in India, backed by authorized national partner **Frootle India**.

## ✨ Key Features & Capabilities

1. **Interactive Cost & Time Savings Calculator (Maid vs. DEEBOT ROI)**
   - Sliders for Home Area (800 – 5,000 sq. ft.) and Monthly Domestic Cleaning Expense (₹2,000 – ₹10,000/mo).
   - Frequency selector: Daily vs. Twice Daily.
   - Real-time computation of Net Annual Savings, Payback Period in months, and Hours Saved per Year (synced with ECOVACS 1.1B+ Global Hours Saved metric).

2. **Pan-India Experience Store Map with Pulsing Interactive Hotspots**
   - Clickable pulsing pin badges (`#184784`) over major urban hubs: Mumbai, Delhi NCR, Bangalore, Hyderabad, Pune, Ahmedabad, and Chennai.
   - Bi-directional sync: Clicking a map hotspot updates the city filter, isolates matching experience centers, and highlights store cards with an active border.

3. **Interactive "Find My DEEBOT" Home Quiz (3-Step Matchmaker)**
   - 3-step decision flow tailored for Indian households:
     - Home Size (< 1,200 sq. ft. 2 BHK, 1,200–2,500 sq. ft. 3–4 BHK, 2,500+ sq. ft. Villa/Duplex)
     - Primary Concern (Heavy Indian Mopping / Curry Stains, Pet & Long Hair Tangles, Zero Maintenance)
     - Flooring & Thresholds (Tiles/Marble, Rugs/Carpets, High Door Thresholds up to 40mm)
   - Dynamic recommendation banner matching best-fit model (N-Series, T50S Pro, T90 Pro, etc.).

4. **Side-by-Side Series & Model Comparison Matrix**
   - Sticky comparison table header (matching site header height).
   - Direct comparison across N-Series, T-Series (T30e, T50S Pro, T90 Pro Flagship), and X-Series.
   - Compares Suction Power (Pa), Mopping Type (OZMO Roller 3.0 vs Dual Spinning), Threshold Climbing (20mm vs 40mm), Carpet Lifting (15mm), and OMNI Station features.

5. **Genuine Accessories & Consumables 4-Column Strip**
   - OEM consumables: Antibacterial Floor Solution (1L), ZeroTangle Main Roller Brush, Washable HEPA Filters, and OMNI Dust Bags.
   - 1-click `+ Add to Cart` buttons.

6. **Slide-Over Cart Drawer**
   - Compact cart badge button in the header.
   - Slide-over drawer with item steppers, live Total Savings computation (MRP vs. Online Price), and a "Convert Cart to Free Home/Store Demo" option.

## 🚀 Getting Started

Simply open `index.html` or `gemini-code-1795190024474.html` in any modern web browser or serve via any static file server:

```bash
# Using Python
python -m http.server 8080

# Using Node.js npx
npx serve .
```
